    Built on AWS

    Serverless end to end, deployed with AWS SAM in Mumbai (ap-south-1). One template, about a rupee a day at hackathon scale.

    • Amazon Bedrock (Nova 2 Lite) reads bills and quotes: three readings in parallel, kept only where they agree.
    • AWS Step Functions runs each household's application as a long-lived workflow: a task token per stage, a nudge when one stalls.
    • Amazon EventBridge Scheduler re-reads official sources every week and flags facts whose page changed.
    • Amazon DynamoDB holds learned tariffs, quote prices, facts, sessions and live counters, with TTLs.
    • AWS Lambda + API Gateway serve WhatsApp and this site; Amplify Hosting serves the page; SSM keeps the secrets.
