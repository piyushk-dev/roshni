    How it's built on AWS

    Everything runs serverless in AWS's Mumbai region and deploys from one AWS SAM template. Each bill is read three times in parallel on Amazon Bedrock, and only the figures the readings agree on are used. Each household's application runs as its own long-lived Step Functions workflow.

    • Amazon Bedrock (Nova 2 Lite) reads bills, quotes and inverter screens, and answers questions using the facts listed above.
    • AWS Step Functions pauses on a task token at each application step. If a step runs long, the timeout sends a reminder.
    • Amazon EventBridge Scheduler re-reads the official sources every week and flags any fact whose page has changed.
    • Amazon Transcribe and Polly handle Hindi voice notes in both directions. S3 keeps the audio for one day.
    • DynamoDB stores learned tariffs, quote prices, facts, sessions and counters. Lambda and API Gateway serve WhatsApp and this site, which is hosted on Amplify.
