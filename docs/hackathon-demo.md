# Three-minute product demo

Use the local branch preview for deterministic features. The existing deployed site remains the cloud bill/voice demo until this branch is separately released.

Before recording, choose English, expand the roof options, set roof area to **300 sq ft**, then run the sample estimate. That caps the example at 3 kW so the quote comparison below uses the same size. Clear any test passport progress. In the in-app browser, use the export preview and copy/selection fallback if downloads are unavailable.

| Time | Show | Explain |
|---|---|---|
| 0:00–0:20 | Existing sample electricity bill estimate | “The family wants lower bills. The companion already calculates size, subsidy and payback. The harder decisions come next.” |
| 0:20–0:40 | Find & compare: real installer directory | “Real published businesses, official local registration check, and no invented ratings. These instant offers are clearly labelled samples.” |
| 0:40–1:05 | Explore quote traps | “₹1.32 lakh looks cheapest, but non-DCR terms remove central assistance. Compare the advance, included scope and actual net cost.” Use anonymous examples; do not name a real company as a trap. |
| 1:05–1:30 | Schemes & budget: DCR evidence → yes; wait 1 versus 6 months | “The family may need to fund months of EMI before assistance arrives. Here is the actual cash requirement and interest. A lower EMI needs the bank to recast the loan.” |
| 1:30–1:50 | Solar passport: outage limitation + handover checks | “If power cuts are the goal, ordinary on-grid solar is the wrong expectation. Before final payment, keep serials, DCR evidence, invoice, commissioning and service terms.” |
| 1:50–2:15 | Generation review: completed month, 400 promised, 280 actual | “70% of the written estimate is a reason to investigate, not proof of dust or breach. The next action is a neutral, evidence-backed installer note.” |
| 2:15–2:35 | First bill: generation 400, import 300, export 150, bill export 100 | “250 units were used directly. The home used 550, net import was 150, and 50 export units need review. Generation is not export.” |
| 2:35–2:50 | Switch to Hindi; save and export passport | “The household owns a portable record and can take it to its installer or DISCOM. It works across brands and does not need identity-document uploads.” |
| 2:50–3:00 | Existing AWS architecture + clear limits | “AI reads bills and quotes; deterministic rules explain decisions. WhatsApp, Lambda, DynamoDB and Step Functions support the journey. No fabricated integrations or impact claims.” |

Do not imply the app contacts vendors, submits official applications, diagnoses equipment, guarantees subsidy, or issues compensation. The strongest demonstration is a correct decision followed by a useful next action.
